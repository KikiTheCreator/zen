# 02 — Existing Tools and the Gap

| Tool | Strength | Weakness for a learner |
|---|---|---|
| **Mobalytics** | Best-known for improvement; "GPI" skill profile (vision, fighting, objectives...) | Scores tell you *that* you're bad at something, not *why* or *what moment*; Overwolf; ads |
| **Blitz** | Auto-imports runes/items in champ select | Encourages copying; teaches nothing |
| **Porofessor** | Scouting the enemy pre-game | Not a learning tool |
| **iTero** | Draft/pick suggestions, post-game review | Black-box suggestions |
| **u.gg / op.gg / lolalytics** | Stats, builds, matchup win rates | Raw numbers; needs knowledge to interpret |
| **Skill Capped / ProGuides** (paid video) | Real teaching content | Not personalized; long videos; not linked to *your* games |
| **YouTube coaches** (Coach Curtis, LS, Broken by Concept podcast, etc.) | Deep concepts | Unstructured; many pre-2026 |

Note: the comparison blogs found are mostly written by competing app makers, so treat their
rankings as opinion.

## The gap = this project's positioning

Nobody does all of these well together:
1. **Moment-level feedback from your own games**, linked to a **short lesson** ("At 7:12 you
   died. Your wave was pushing toward the enemy and their jungler was last seen bot top-side...
   → Lesson: tracking the jungler and wave state").
2. **Explain the why** behind builds/runes/picks (options + reasoning), so the player learns
   to adapt instead of copying.
3. **Structured curriculum** in learning order, with drills in Practice Tool and quizzes.
4. **Champion pool coaching**: build a small pool that covers matchups and learn it deeply.
5. **Mental**: session limits, tilt check-ins, reflection journal.
6. **Native language** (Data Dragon has `es_*`/`pt_BR`; most coaching content is English).
